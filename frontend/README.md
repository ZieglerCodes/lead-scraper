# Lead Scraper React frontend — Phase 4

See [../README_PHASE4.md](../README_PHASE4.md) for detailed setup. The Netlify site is built from this directory using the root `netlify.toml`.

Set `VITE_API_BASE_URL`, `VITE_SUPABASE_URL`, and `VITE_SUPABASE_PUBLISHABLE_KEY` in the Netlify site environment. NEVER supply service-role keys, database passwords or Google API keys through Vite environment variables.

Local commands: `npm install`, `npm run build`, `npm run dev`.
